## 🏦 About The Project

A **complete end-to-end Machine Learning pipeline** for predicting bank loan approval status — covering data preprocessing, feature engineering, baseline model training, hyperparameter optimization, evaluation metrics, and automated visualization reports.

Implements **8 ML algorithms** and performs **RandomizedSearchCV-based hyperparameter tuning**, automatically comparing all models and generating publication-ready PNG plots.

> 📊 Designed to be easily extendable — drop in a new dataset and the pipeline handles the rest.

<br/>

<div align="center">

| 🤖 Models | 🔧 Tuning | 📊 Metrics | 📈 Output |
|:---:|:---:|:---:|:---:|
| 8 ML algorithms | RandomizedSearchCV | Accuracy + ROC-AUC | 3 auto-generated PNG reports |

</div>

## 🧾 Pipeline Workflow

<br/>

```
  📂 Load Dataset
       │
       ▼
  🧹  Preprocess Data
      Remove whitespaces · Handle missing values · Label encode
       │
       ▼
  🔧  Feature Engineering
      Loan-to-income ratio · Total assets · Asset-to-loan ratio · Debt burden
       │
       ▼
  ✂️  Train-Test Split
      X_train · X_test · y_train · y_test
       │
       ▼
  📊  Baseline Model Training
      Accuracy + Cross-Validation ROC-AUC
       │
       ▼
  ⚙️  Hyperparameter Tuning (RandomizedSearchCV)
      RF · Gradient Boosting · Extra Trees · Logistic Regression
       │
       ▼
  🏆  Final Evaluation (All Models)
      Accuracy · ROC-AUC · CV ROC-AUC
       │
       ▼
  📈  Auto-Generate Visualization Reports (PNG)
      Model Comparison · Hyperparameter Analysis · Confusion Matrices
```

## 📝 Dataset Requirements

Your dataset must include the following columns for full pipeline functionality:

<div align="center">

| Column | Description |
|:---:|:---|
| `loan_status` | 🎯 Target variable (approved / rejected) |
| `loan_amount` | Loan amount requested |
| `income_annum` | Annual income of applicant |
| `loan_term` | Loan duration |
| `education` | Applicant education level |
| `self_employed` | Employment type (Yes / No) |
| `residential_assets_value` | Residential asset value |
| `commercial_assets_value` | Commercial asset value |
| `luxury_assets_value` | Luxury asset value |
| `bank_asset_value` | Bank asset value |

</div>

> ✅ Extra columns beyond these are supported automatically by the pipeline.

## 🚀 How to Run

**1. Install dependencies**

```bash
pip install pandas numpy scikit-learn seaborn matplotlib scipy
```

**2. Run the pipeline**

```bash
python main_hypertuned.py
```

> ✅ The script will preprocess data, train all 8 models, tune hyperparameters, evaluate results, and auto-save 3 PNG reports.

## 🏆 Best Model Selection

The pipeline automatically compares all 8 models across three metrics and identifies the strongest candidate for deployment:

<div align="center">

| Metric | Description |
|:---:|:---|
| ✅ Test Accuracy | Final held-out test set accuracy |
| 📈 CV ROC-AUC | Cross-validated area under the ROC curve |
| 🎯 Test ROC-AUC | ROC-AUC on the test split |
